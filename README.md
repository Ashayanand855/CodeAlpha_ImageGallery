# Image Gallery

A modern, responsive image gallery built with HTML, CSS, and vanilla JavaScript. Features dynamic category filtering and an interactive lightbox for a seamless portfolio experience.

## Features
- **Responsive Grid**: Adapts beautifully to desktop, tablet, and mobile screens.
- **Interactive Lightbox**: Immersive image viewing with Next/Prev controls and keyboard support.
- **Dynamic Filtering**: Click category chips to filter images smoothly.

## Setup
No build steps required. Just open `index.html` in your web browser to view the gallery.

## Customization
- **Add Images**: Replace the `src="#"` attributes in `index.html` with your image paths.
- **Categories**: Change the `data-filter` and `data-category` attributes in `index.html`.
- **Styles**: Edit the CSS variables (`:root`) in `style.css` to customize colors, fonts, and spacing.
